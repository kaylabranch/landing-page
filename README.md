# kaylabranch.com

Super simple personal landing page, live at [kaylabranch.com](https://kaylabranch.com).

## Stack

Static HTML and CSS, no build step and no JavaScript. Hosted on GitHub Pages.

## Files

- `index.html`: page content
- `style.css`: styles, with colors defined as CSS variables
- `favicon.svg`: site icon

## Local preview

Open `index.html` in a browser.
